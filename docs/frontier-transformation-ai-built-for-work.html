How Work Evolves with AI

Assist

You create.
AI assists.

Available Premium capabilities working inside Word, Excel, PowerPoint, Outlook & Teams and inside M365 Copilot—with WorkIQ, reasoning agents like Researcher and Analyst, and reusable Assist Agents.

Delegate

You define the work.
AI executes.
You refine and edit.

With Cowork, skills really take shape: leverage personal, shared, and M365 Admin Center Tools catalog skills (including 30+ Microsoft skills for Dynamics 365 Sales & Customer Service), or schedule recurring tasks (e.g., 6:00 AM daily) ready for human-in-the-loop review.

Build

You spec.
AI builds.

Democratized in natural language along two parallel pathways: Copilot Code and Copilot Studio—running in their execution containers and governed by Power Platform Managed Environment controls.

Automate

Persistent Autopilots
acting on your behalf.

Where persistent Autopilots in the GAL step in to handle ongoing work on your behalf—scheduling meetings (+5 min after :00/:30), pinging you on Teams, and coordinating with a Briefing Autopilot in OneDrive to scale across 100+ people.

Parallel Build Pathways, Respective Containers & Managed Environment Controls

How democratized creation in Copilot Code and Copilot Studio runs in respective execution containers—the Copilot Managed Runtime and Power Platform Environments—governed and influenced by Power Platform Managed Environment controls and M365 Admin Center + Agent 365.

Governed by Microsoft 365 Admin Center + Agent 365

Single Enterprise Control Plane: Consistent Access & Identity • Credit Allocation • Administrative Policies Across Thousands of Users

Pathway 1 • Build Pillar

1. Copilot Code

Brings the power of coding agents to thousands of knowledge workers who describe what they need in natural words—just like pro developers—to create almost anything.

  • Create & Publish Managed Apps
  • No GitHub Copilot Subscription Needed
  • Integrates with GitHub Repos & CLIs
  • Seamless No-Code to Pro-Code Handoff
Pathway 2 • Build Pillar

2. Copilot Studio

Designed when an evolving business process needs multi-step reasoning, deterministic orchestration, and dedicated user experiences working in harmony:

  • Custom Agents — Runs in Power Platform Environments
  • Workflows — Runs in Power Platform Environments
  • Managed Apps (Risk Tracker) — Runs on Copilot Managed Runtime

↓ Copilot Managed Runtime

Where Managed Apps Run: Managed Apps created in both Copilot Code and Copilot Studio—along with apps built in Lovable and other coding agents—converge to deploy and run inside the Copilot Managed Runtime.

↓ Power Platform Environments

Where Studio Agents & Workflows Run: Custom agents and workflows built in Copilot Studio execute in dedicated Power Platform Environments (independent of the Copilot Managed Runtime).

⇅ Both Containers Associated With & Governed by Power Platform Managed Environment Controls

While Managed Apps and Copilot Studio Agents & Workflows execute in their respective containers, both are governed and influenced by the Power Platform Managed Environment controls to which they are associated—unlocking 1,500+ governed enterprise connectors, DLP & data policies, and lifecycle guardrails trusted by millions worldwide.

Just a Few Prompts Away

1. Pro-Dev Collaboration & Handoff

When a business process created by a knowledge worker grows to support 100+ monthly users, it often outgrows personal day-to-day maintenance. Because the foundation in Build is natively compatible, transitioning to a professional developer using the GitHub Copilot App and Copilot CLI is just a few prompts away—no rewrite required.

  • GitHub Copilot App & Copilot CLI
  • Shared Git Repositories & Worktrees
  • Zero-Throwaway Knowledge Worker → Pro-Dev Handoff
When Complexity Calls for More

2. Level Up into Microsoft Foundry & Foundry Agents

Stepping into the pro-dev persona opens the entire world of Microsoft Foundry—where engineering teams can optimize complex workloads with an even broader catalog of 1,800+ frontier, open-weight, and domain-specialized models, custom fine-tuning, automated evaluations, safety guardrails, and pro-code Foundry Agents.

  • 1,800+ Frontier & Specialized Models
  • Foundry Agents & Multi-Agent SDKs
  • Custom Fine-Tuning, Evals & Guardrails
Operational Maturity

3. Enterprise ALM & Managed Apps Blueprint

Here, formal Application Lifecycle Management (ALM) is introduced—bringing Git source control, branch isolation, automated testing, and repeatable dev → test → prod promotion. Not every knowledge worker process needs this evolution, but when it does, the pathway is ready.

  • Git Source Control & Branch Isolation
  • Governed Dev → Test → Prod Promotion
